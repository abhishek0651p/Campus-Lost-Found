About This Project

Campus Lost & Found with Smart Matching System

🎓 College Project

This is a campus-wide system that helps students report items they have lost or found. The system uses a C++ smart matching engine that compares reports across multiple dimensions — category, color, brand, location, date, description keywords, and tags — to identify possible matches and help reunite owners with their belongings.

🛠 Technology Stack

  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Backend / Core Engine: C++17 (matcher algorithm)
  • Data Storage: JSON flat-file
  • Icons: Lucide Icons

⚙️ How Smart Matching Works

The C++ matching engine uses a weighted scoring algorithm across 7 criteria: Category (25%), Location Proximity (20%), Description Keywords (15%), Color (10%), Brand (10%), Date Proximity (10%), and Tag Overlap (10%). Matches scoring above 30% are surfaced to users for review.
